# Idea notebook

## Goal

John wants to capture brief ideas and brain dumps in a simple web app on phone
and desktop. Agents should categorize and link the ideas, explore them through
research or small experiments, and leave useful findings for future reference.
Concrete implementation work can become a Bead or GitHub issue, with a link
back to the idea and its evidence.

## Current decision

Learn OpenRig before designing or building a separate application. This lab is
an experiment in the existing tool. No notebook frontend has been built.

## Knowledge

Keep original thoughts distinct from interpretations. An observation is not
an established conclusion. A useful finding includes its question, method,
evidence, limits, and next step. Later experiments should consult related
earlier findings instead of repeating them unknowingly.

## Boundaries

Only one researcher runs in the lab. Do not create teams, install packages,
alter the host configuration, publish results, or act on other repositories.
Use OpenRig's internal queue for exercises. The parent session records the
overall investigation in Beads; the lab agent should not access that database.
