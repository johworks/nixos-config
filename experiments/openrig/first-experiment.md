# First OpenRig experiment

Explore whether OpenRig supplies the execution and context foundation for the
idea notebook. This is an investigation of the installed tool, not an assignment
to implement the notebook.

1. Read and claim this queue item. Read stream item `notes-lab-001` and its
   classification using `rig stream` and `rig project` (consult their help).
2. Retrieve `notes-lab/notes.md#goal` using `rig context get`, then read the
   current decision and knowledge sections as needed.
3. Inspect the installed help/context for the stream, classifier, queue, and
   context tools. Run a small read-only check of each relevant surface.
4. Write `findings/first-experiment.md`: original idea, what you actually
   observed, how the four surfaces fit together, what still needs authored
   wiring, and the smallest next experiment. Cite actual commands and relevant
   context references. Say that intake/classification was initially driven by
   the parent session; do not claim it happened autonomously.
5. Update and close this queue item only once that file exists. Give its path
   and verification performed. Report the result, then wait.

Keep this to a small local experiment. Do not browse the web, implement an app,
edit files outside this workspace, create other queue items, launch agents,
alter configuration, or contact external systems.
