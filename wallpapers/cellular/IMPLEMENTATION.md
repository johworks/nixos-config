## Result

Replaced the Life display with a stable hill/tree or mountain/lake composition.
Sunny, cloudy, and rainy palettes affect sky, terrain, foliage, snow, and water.
Clouds drift; rainy adds falling particles. Manual controls use the existing
Plasma configuration map, including persistent pause and context-menu weather
choices. No location or external weather source is used.

landscape.js is a deterministic Canvas renderer with integer rectangle spans
for every layer. The framebuffer is bounded at 480 × 300 and its dimensions
are capped together to preserve aspect. A uniformly scaled 320 × 180 composition
extends sky/terrain to different screen shapes. WeatherScene.qml supplies the
single clock, constant 20 FPS timer, capped elapsed time, and hidden/minimized
window/item gating. Speed changes motion, not FPS. main.qml remains a thin
WallpaperItem with the existing org.nixos.cellular identity.

The existing Life source/tests are unused but retained. No Nix module or host
configuration changed. No desktop activation, rebuild/switch, package install,
branch changes, publishing, or Git commits were performed. Beads history was checkpointed with bd dolt commit. Existing managed
AGENTS.md changes are unrelated startup material and were not edited.
